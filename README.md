Object Oriented Programming with C++ — Unit I

Overview

This folder contains the introductory C++ programs for Unit I. The programs build the foundation required for Object-Oriented Programming, starting from basic C++ syntax and progressing to classes, objects, constructors, destructors, static members, inline functions, and friend functions.

Topics Covered

1. Basic Data Types

Introduction to variables and fundamental C++ data types.

2. If-Else

Demonstrates conditional execution using if, else if, and else.

3. Loops and Arrays

Introduces repetitive execution and array-based data storage.

4. Functions

Demonstrates defining, calling, and using functions to organize C++ programs.

5. Classes and Objects

Introduces the basic building blocks of OOP:

Classes

Objects

Data members

Member functions

6. Constructors and Destructors

Demonstrates special member functions used for object initialization and cleanup.

7. Static Members

Demonstrates members shared at the class level rather than belonging to individual objects.

8. Inline and Friend Functions

Demonstrates inline functions and friend functions that can access private/protected class members when permitted.

Compilation

Using GCC:

g++ -std=c++17 "01_basic_data_types.cpp" -o program

Run on Linux/macOS:

./program

Run on Windows:

.\program.exe

Compile each .cpp file separately.

Learning Objectives

After completing Unit I, you should be able to:

Write basic C++ programs.

Use variables and data types.

Apply conditional statements.

Use loops and arrays.

Create and call functions.

Define classes and create objects.

Understand constructors and destructors.

Use static class members.

Understand inline and friend functions.

Requirements

C++ compiler such as GCC, Clang, or MSVC.

C++17 or later is recommended.

Note

Each source file is an independent example and normally contains its own main() function, so the files should not all be compiled together.
